# Code of Conduct

x2c welcomes participation in its project spaces. This document sets practical
boundaries for that participation.

Keep issues, pull requests, and other contributions relevant, constructive,
and reasonably civil. Harassment, threats, spam, and deliberate disruption are
not welcome.

The Project Lead may close, remove, or decline submissions and restrict
participation when needed to keep project spaces useful and civil.

Conduct outside x2c's project spaces is outside the scope of this project.
