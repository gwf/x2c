# Code of Conduct

x2c is a software project, not a managed community. This document exists only to establish practical boundaries for participation in its project spaces.

Keep issues, pull requests, and other contributions relevant, constructive, and reasonably civil. Harassment, threats, spam, and deliberate disruption are not welcome.

Maintainers may close, remove, or decline contributions—and restrict participation—when they judge it useful to the project. They are not obligated to host debates unrelated to the software or to provide a comprehensive system of community governance.

Conduct outside x2c's project spaces is outside the scope of this project.
