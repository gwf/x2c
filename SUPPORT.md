# x2c support

x2c is experimental and is provided without a support commitment or service
level agreement. The documentation and repository history are the current
public support resources.

The project is not accepting external code contributions. See
[`CONTRIBUTING.md`](CONTRIBUTING.md). Security issues require a private report
under [`SECURITY.md`](SECURITY.md), not a public support request.

Use the [issue tracker](https://github.com/gwf/x2c/issues) for bug reports
and documentation problems. Include the revision, platform, and a small
reproduction where possible. Reporting an issue does not imply a response
or resolution commitment.

There is no separate public discussion forum at launch.
