# Runtime (`lib/`)

Use the [agent directory](../agents/README.md) for task routing and relevant
technical references; the [root instructions](../AGENTS.md) own publication.

Runtime code is an example for ordinary x2c programs. Reuse the enforcement
already established by verified entries in the relevant section of
[x2c philosophy](../agents/x2c-philosophy.md); partial and decision entries
identify questions still to be settled.

The compiler emits calls into this runtime and the bootstrap compiles against
it, so public signatures are effectively ABI. Preserve them unless the task
authorizes a compatibility change.

`lib/x2c.x` is generated by `lib/Makefile`; change its inputs rather than
editing it by hand.

x2c does not expand C macros: declarations must be visible without `#if` or
macros that expand to declarations. See
[Preprocessing](../agents/x2c-development-guide.md#preprocessing).
