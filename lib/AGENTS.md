# AGENTS - Runtime (`lib/`)

Read the root `AGENTS.md` first. Open only the section of
`agents/x2c-philosophy.md` relevant to the work. Runtime-specific notes:

- `lib/` is the exemplar bar for the whole repo. Rely only on verified ledger
  entries in the philosophy doc; partial and decision entries name work still
  to be settled. Never duplicate a verified contract's enforcement site.
- The compiler emits calls into this runtime and the bootstrap chain compiles
  against it - public signatures are effectively ABI. Use focused self-host
  checks during development when they answer a live question. For publication,
  use the root rule; do not add a separate broad gate.
- `lib/x2c.x` is generated by `lib/Makefile`; never edit it by hand.
- X2C never expands macros: no `#if` around declarations, no macros that
  expand to declarations. See "Preprocessing" in
  `agents/x2c-development-guide.md`.
