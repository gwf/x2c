# Contributing to x2c

x2c is not currently accepting external code contributions.

Please do not submit pull requests, patches, or code intended for inclusion in
the official project. Unsolicited code submissions may be closed without
review. The public source remains available for use, study, modification, and
forking under its applicable licenses.

Security reports must follow [`SECURITY.md`](SECURITY.md) and must not include
vulnerability details or secrets in a public issue.

## Future contribution policy

If the project opens external contribution intake, this file will be replaced
with the complete source, test, review, contributor-certification, and
licensing requirements. Unless the project announces different terms,
intentional contributions accepted at that time will be licensed under the
Apache License 2.0 as described by Section 5 of that license.

No contributor license agreement or copyright assignment is currently
required or offered. Any future contribution requirements will be published
here before the project starts accepting code.
