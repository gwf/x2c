# Contributing to x2c

x2c welcomes bug reports, ideas, documentation corrections, and pull requests.
It is maintained by one person. I consider feedback as time permits and choose
the project's direction. A submission does not guarantee a response, review,
fix, or merge.

For a substantial change, open an issue before investing in a pull request.
Small, focused fixes can go directly to a pull request. Please explain the
change and how you checked it. Ideas are welcome, but an issue does not put a
feature on a roadmap.

Target pull requests at `dev`, where everyday integration work happens.
`main` holds released source only. Forks are welcome under the applicable
licenses.

Security reports must follow [`SECURITY.md`](SECURITY.md) and must not include
vulnerability details or secrets in a public issue.

## Contribution terms

Submit only work that you have the right to contribute. Unless you explicitly
state otherwise, intentional contributions submitted for inclusion in x2c are
under the Apache License 2.0 terms described in Section 5 of that license.
If you intend different terms, state them clearly before submitting; the
project may be unable to accept the contribution.

No contributor license agreement or copyright assignment is required.
