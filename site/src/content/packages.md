---
title: Put libraries to work
---

Draw a chart, build a terminal app, query a database, or train a model.
Below is one working example from each package, with its code, its result,
and the complete source and setup instructions.

Packages give libraries their own namespaces, so you use them together
without name collisions. Build once, then `import` by name. Shims and
adapters add idiomatic x2c types and methods, and the native API is still
available. `x2c bind` writes the mechanical part of a new
package from a C header.
