---
title: Code is Magic
lede: "The compiler is written in x2c, and your program can call the compiler."
---

A code literal is a `List`, so you can match it and rebuild it. Put `meta`
in front of a function and the compiler will run it. Macros are typed
templates over parsed syntax, a decorator rewrites the declaration after
it, and `keyword` makes a macro a statement. Reflect on a struct at compile
time and nothing is left over at run time.

Everything in the Power section was built this way. So was the compiler.
