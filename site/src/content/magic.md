title: Code is Magic
lede: "The third idea: a language that extends itself."
---

`meta` runs a function at compile time. A `macro` is a typed template over
parsed syntax, a decorator rewrites the declaration after it, and `keyword`
makes a macro a statement. A code literal is a `List`, so the tools for
data rewrite code. `try`, `match`, `class`, and the compiler are written
this way. Nine examples.
