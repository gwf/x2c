---
title: Code is Power
---

Code becomes powerful when a few simple pieces open up many possibilities.
Each capability becomes more useful through the others: collections give
your types something to build on, iterators connect operations into flows,
and imports bring C libraries into the same style of code.

With x2c, those combinations turn into working tools. Turn a stream of text
into a ranked result. Build and query a search index. Send work to another
thread and bring the answer back. Run a daily survey that reclaims working
storage after each file and each day, without individual free calls.
Substantial computations become compact enough that you can still see the
idea running through them.

The pieces are small. What you build with them needn't be.
