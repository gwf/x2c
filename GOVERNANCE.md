# x2c governance

This document defines the initial governance of the official x2c project.
It is intentionally small while the project remains founder-led.

## Project Lead

Gary William Flake is the Founder and Project Lead. The Project Lead has final
authority over:

- the official language definition and compatibility claims;
- the reference compiler, runtime, standard library, and release artifacts;
- the official source repositories, websites, and project infrastructure;
- appointments of maintainers and delegation of project responsibilities;
  and
- use of official project names and marks.

The Project Lead may seek review and consensus before making a decision, but
consensus is not a condition of authority. Maintainers exercise only the
authority explicitly delegated to them.

## Official project and forks

The Apache License 2.0 permits forks and independent development. A fork does
not become an official x2c release merely because it is based on x2c source.
Official status depends on authorization by the Project Lead and compliance
with the project's trademark policy.

## External contributions

The project is not currently accepting external code contributions. See
[`CONTRIBUTING.md`](CONTRIBUTING.md) for the current participation policy.

## Succession

The Project Lead may designate a successor or replace this founder-led model
with another governance structure.

## Changes to this document

The Project Lead approves changes to this governance document.
