## Result

The landing page features one working example from each of the ten packages,
with balanced code excerpts, actual output, and links to source and setup.
Torch uses Gary's composed-module, Adam, and checkpoint example.

Navigation reads love, power, magic | install, packages, about, docs, source.
Only the first three are red; docs and source have external-link icons.
The body follows Love, Power, Magic, Install, Packages, and Go further;
About, Docs, and Source remain their existing destinations. Section colors
alternate automatically with sibling position. Install has the shared large
heading and adds runnable strings and compile-time Lisp commands.

## Package presentation

The introduction explains package namespaces, isolation, idiomatic shims and
adapters, retained native APIs, and optional Lisp bindings and decorators.
A caption-free shell box floats right so introductory prose flows below it.

The full-width gallery reuses `FeatureCarousel`. Each slide pairs dark code
with a light caption. Odd slides put code left and caption right; even slides
reverse the pair. Below 640px, code precedes caption in one column. Excerpts
are 21-23 displayed lines and no more than 53 authored columns; narrower
panels wrap. The highlighter's inline text color is overridden in light
caption output blocks.

## Media

All results come from actual examples, not browser reimplementations.
Raylib loads bundled Lato Regular TrueType text, renders at 2160x960, then
resizes to 1440x640 for smooth edges. The memory profile enables upstream
TrueType support without a display or GPU. The font's license, pinned origin,
and checksum travel with the example. Existing PNG geometry/hash expectations
are refreshed; the other raylib image retains its checksum.

Game of Life is a 238-frame, 20.37-second GIF recorded from the actual 64x20
terminal run. A play/pause control swaps it with a still poster, also used
for reduced-motion preferences and without JavaScript.

Capture provenance and full logs are under `.context/package-gallery/`
and `debug/`; shipped media lives under `site/public/packages/`.

## Plan review

The package catalog and source own scope and behavior; the site summarizes
and links rather than introducing another registry. Existing Markdown,
carousel, navigation, palette, and base-aware URL conventions are reused.
The only new client behavior controls recorded GIF playback. The chart uses
raylib's existing drawing/font APIs; its font-size check catches upstream's
silent fallback to the default bitmap font. No compiler semantics, package
API, or additional validation process is introduced.
