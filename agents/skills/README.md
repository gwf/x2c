# Project skills

[agents/README.md](../README.md) is the task-routing directory. Skills are
authored here; `.agents/skills` and `.claude/skills` expose this same directory
to Codex and Claude Code.

Each `<name>/SKILL.md` provides a repeatable x2c task workflow with a clear
trigger and observable completion condition. Keep shared workflow in root
instructions, link to technical references, and use the book for language
semantics. Companion `agents/openai.yaml` files provide UI descriptions and
prompts where present.
