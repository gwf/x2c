# Agent documentation (`agents/`)

[README.md](README.md) routes tasks to skills and technical references.
The [root instructions](../AGENTS.md) own verification and delivery.

- Keep repository workflow, style, debugging, and implementation references
  here. Link language and library semantics to the user-facing book in
  `docs/` instead of maintaining a second description.
- Verify file names, APIs, flags, and commands against the current tree.
  Repair or remove stale guidance in its existing location.
- Compile complete code samples with the current `builds/0/x2c`. A guide may
  state once that its fragments are illustrative. `bin/x2c` is the bootstrap
  compiler unless stage 0 has intentionally been installed.
- Keep Logger and compiler diagnostics guidance in
  `logger-and-diagnostics-guide.md`.
- `x2c-module-catalog.md` is generated by `make doc-generate`; edit its inputs
  rather than the generated file.
- Author skills in `agents/skills/`; `.agents/skills` and `.claude/skills`
  expose the same directory to Codex and Claude Code.
