# Security policy

x2c is experimental software and does not yet have a supported stable release
or a guaranteed security-response service. Security reports are nevertheless
welcome and should be handled privately.

## Reporting a vulnerability

Report vulnerabilities privately to [security@x2c-lang.dev](mailto:security@x2c-lang.dev).
Do not place vulnerability details, exploit code, credentials, or other
secrets in a public issue.

Include the affected revision, platform,
reproduction steps, expected impact, and any suggested mitigation. The
project will acknowledge and prioritize reports when maintainer capacity
allows, but no response or remediation deadline is currently promised.

## Supported versions

There are currently no stable versions receiving security support. This
section will list supported release lines before x2c makes a stability or
security-maintenance commitment.
