# x2c Language Support extension support

This preview extension is experimental and has no support commitment or
service level agreement.

Report bugs and documentation problems in the
[x2c issue tracker](https://github.com/gwf/x2c/issues). Include the extension
version, VS Code version, and a small source example. Send usage questions to
[support@x2c-lang.dev](mailto:support@x2c-lang.dev).

Do not include vulnerability details, credentials, or other secrets in a
public report. Follow the
[x2c security policy](https://github.com/gwf/x2c/blob/main/SECURITY.md) and
report vulnerabilities to [security@x2c-lang.dev](mailto:security@x2c-lang.dev).
