# Build and support files

These files support the build, the compiler, and the release. The root
`Makefile` includes every `.mk` file here except `x2c.mk`. Each file's header
comment, or its directory's README, gives the details.

| Entry | What it is |
| --- | --- |
| `branch.mk` | Turns the Git branch name into the suffix of installed binaries. |
| `build-config.mk` | Sets compiler flags for the debug and optimize build modes. |
| `build-mode` | The tracked default build mode; an untracked `build-mode.local` overrides it. |
| `compiler-prelude.x` | Syntax that every unit starts with: macros and keyword aliases collected before the runtime prelude. |
| `help.mk` | The script that prints `make help` from the Makefile's `##@` groups and `##` comments. |
| `init.xlisp` | The Lisp standard environment that the example Lisp shell loads. |
| `make-command.mk` | Selects the Make on `PATH` and rejects checkout paths with whitespace. |
| `meta-helper.x` | The main loop of a project's compile-time helper program. |
| `meta-queries.x` | Generated by `tools/gen-meta-queries.sh`: the compiler operations a meta helper asks for. |
| `x2c-payload.x` | Installs a native prefix or the development commands. |
| `x2c.mk` | Make variables and rules for building x2c programs, used by `unittest/`. |
| [playground/](playground/README.md) | The playground compilation service. |
| [release/](release/README.md) | Public release operations and website deployment. |
| `syntax/` | The source grammar, lexical rules, and syntax additions as List data. |
| [vsc-extension/](vsc-extension/README.md) | The VS Code extension. |
