# Visibility of each runtime module in the generated library reference.
#
# path|visibility|note
#
#   api       user-callable; gets a full generated page of signatures.
#   contract  described by docs/src/library/overview.md; no user-callable
#             surface of its own.
#   optional  shipped but not in the implicit prelude; its page shows the
#             include line, then the note, if any.
#   internal  runtime-internal; listed with its reason and nothing else.
#
# Every lib/*.x file needs exactly one row. tools/gen-api-reference fails
# rather than guessing, so a new module cannot be silently dropped from the
# reference. lib/x2c.x is excluded: lib/Makefile generates it.
